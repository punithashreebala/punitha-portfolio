# Punitha Ravichandran — Portfolio

A responsive, single-page portfolio website built with HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish for free
- **Netlify:** sign in, choose Add new site → Deploy manually, then drag the extracted folder into the upload area.
- **GitHub Pages:** create a repository named `your-username.github.io`, upload `index.html` and the `assets` folder, then enable Pages in repository settings.
- **Vercel:** import a Git repository containing these files or deploy the folder using Vercel's supported workflow.

The resume PDF is in `assets/` and is linked from the page.

## Before publishing
- Add your GitHub profile URL.
- Replace the work-highlight cards with verified project titles, descriptions, screenshots and demo/repository links.
- Check contact details and resume are current.
